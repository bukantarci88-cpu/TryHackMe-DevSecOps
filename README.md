# 🛡️ TryHackMe – DevSecOps

A hands-on cybersecurity learning repository focused on integrating security throughout the software development lifecycle. This repository contains notes, practical exercises, techniques, and key concepts from the **TryHackMe DevSecOps Path**.

The path covers **Secure Software Development, CI/CD Pipeline Security, Application Security, Container Security, Docker, Kubernetes, and Infrastructure as Code (IaC)**.
